Публикация в браузере и на телефон (GitHub Pages)

  1. Сохраните этот файл под именем index.html.
  2. Загрузите index.html в репозиторий на GitHub и включите Settings → Pages (ветка main, папка / (root)).
  3. Откройте ссылку в Chrome на телефоне и нажмите «Добавить на главный экран».

Данные по каждому месяцу сохраняются локально в памяти браузера (localStorage): закрыли один месяц, открыли следующий и в любой момент можете переключиться между месяцами для просмотра.
